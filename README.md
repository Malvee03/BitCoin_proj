Para rodar o código e abrir no navegador, execute o seguinte comando no terminal: streamlit run proj_bitcoin.py

O projeto tem como foco prever quedas e altas do BitCoin, sem descartar ideias de adicionar mais cripto ao decorrer do tempo.

Libs usadas: Streamlist, Pandas, NumPy, SQLite e Ploty

DB: db_bitcoin_proj
